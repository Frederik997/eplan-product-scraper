# EPLAN Product Scraper

A Python web scraping project built with Playwright that extracts
product information from the EPLAN Data Portal and exports the
results to an Excel spreadsheet.

## Technologies

- Python
- Playwright
- OpenPyXL

## Features

- Extracts product URLs from paginated lists
- Scrapes product information
- Handles dynamically loaded pages
- Handles failed product requests
- Tracks failed URLs for later processing
- Sorts products by manufacturer
- Exports data to Excel
